# 小说分享阅读功能设计文档 (Design Spec)

## 1. 业务背景
在当前的对话式 AI 产品中，用户经常让 AI 创作长篇连载小说。然而，在聊天对话框里阅读大量文本体验较差，且难以方便地分享给他人。为了解决这个问题，我们需要提供一个“小说阅读与分享”功能，允许用户将对话中生成的小说内容导出为一个可离线阅读、排版精美的 HTML 文件，方便通过微信、邮件等方式直接分享给朋友阅读。

## 2. 核心架构与技术路线
本功能采用 **纯前端（Client-side）生成方案**，无后端依赖，零存储成本。
*   **内容范围**：静态累计分享（包含目录和当前已生成的所有章节）。
*   **提取机制**：用户手动勾选对话流中的有效小说段落，系统辅助预选。
*   **产物形态**：一个独立的、包含所有内联样式（CSS）和交互逻辑（JS）的单页面 HTML 文件。

## 3. 功能模块详细设计

### 3.1 导出触发与交互 (Export UI)
*   **入口**：在聊天界面的显著位置（如输入框上方操作栏或侧边菜单）新增“导出小说 (HTML)”按钮。
*   **内容选择弹窗 (Selection Modal)**：
    *   点击导出后，前端脚本扫描当前对话流中的所有“AI 回复”节点。
    *   弹出一个模态框，列表形式展示这些回复的摘要（标题或前两句话）。
    *   **智能辅助预选**：前端通过正则表达式（如匹配 `第[一二三四五六七八九十百千万\d]+章` 等特征）自动**默认勾选**疑似小说正文的段落，过滤掉简短的闲聊回复。
    *   **用户控制**：用户可以手动取消勾选不需要的段落，或补充勾选漏掉的内容，确保导出的内容纯净。
    *   **操作反馈**：底部显示“已选择 X 段内容”，点击“生成文件”开始打包。

### 3.2 内容解析与组装 (Content Parsing)
*   **内容提取**：根据用户在弹窗中最终确认的列表，提取对应气泡内的 DOM 结构或原始 Markdown 文本。
    *   保留必要的段落标签 `<p>`、换行 `<br>` 和标题标签 `<h1>` / `<h2>`。
    *   如果提取的是 Markdown，需在前端转换为 HTML 格式。
*   **数据结构**：
    将提取的内容结构化，例如转换为 JSON 数组：
    ```json
    [
      { "title": "第一章：深渊的凝望", "content": "<p>正文内容段落一</p><p>正文内容段落二</p>" },
      { "title": "第二章：遗迹的回声", "content": "<p>正文内容段落三</p>" }
    ]
    ```

### 3.3 模板渲染与文件下载 (Render & Download)
*   **基础模板 (Base Template)**：
    前端项目中内置一个预先设计好的 HTML 字符串模板。该模板包含一个阅读器所需的完整骨架、CSS 样式和 JavaScript 交互逻辑。
*   **数据注入**：
    将结构化后的 `novelData` 遍历，生成左侧的 `<ul>` 目录树和右侧的正文区块 DOM 字符串，替换掉模板中的特定占位符（如 `<!-- INJECT_TOC -->` 和 `<!-- INJECT_CONTENT -->`）。
*   **文件生成**：
    *   使用 `new Blob([htmlString], { type: "text/html;charset=utf-8" })` 将拼接好的完整 HTML 字符串转换为 Blob 对象。
    *   创建一个隐藏的 `<a>` 标签，设置 `href = URL.createObjectURL(blob)`。
    *   设置 `download` 属性为动态生成的文件名（如 `我的小说_20260424.html`）。
    *   触发 `a.click()` 实现浏览器原生下载。

## 4. 导出后的阅读器特性 (Reader Experience)
朋友收到该 HTML 文件并在浏览器（如微信内置浏览器、Safari、Chrome）中打开后，将获得以下体验：
*   **单文件便携**：所有 CSS/JS 均内联，无需外部请求，支持完全离线阅读。
*   **响应式布局**：
    *   **PC 端**：左侧固定目录侧边栏，右侧正文区，沉浸式阅读。
    *   **移动端**：侧边栏默认隐藏，提供悬浮按钮或手势唤出目录面板；正文区占满屏幕。
*   **阅读偏好设置**：
    *   **主题切换**：提供默认（浅色）、夜间（深色）、护眼（羊皮纸色）三种主题配色。
    *   **字号调节**：支持通过 `A+` / `A-` 按钮动态放大或缩小正文字体。
*   **平滑滚动与锚点**：点击目录项可平滑滚动至对应的章节标题位置。

## 5. 后续扩展考虑 (Future Scope)
*   （可选）支持导出为 ePub 格式，以兼容专业的电纸书阅读器（如 Kindle）。
*   （可选）允许用户在导出前自定义书名和作者名。
